# 最初の顧客面談スプリント

更新日: 2026-08-10

この文書は、`AU-001` の顧客候補5人へ行動面談を実施し、最初に売る用途、制作障壁、有償検討の根拠を7日間で集めるための実行手順である。

商品説明や販売を目的にしない。未来の希望より、最近の実際の行動、停止、支出、代替手段を確認する。

## 今回検証する一組

| 項目 | 内容 |

| 面談時間 | 1人25〜30分 |

## 確かめる仮説

```text
自分の経験、知識、物語、企画、価値観を動画にして副業の反応を試したい人は、
制作工程、編集、複数サービスの操作、時間または費用によって完成・公開できず、
自分の意図を保った最初の一本と、その後も作れる制作の仕組みに価値を感じる。
```

確認したいのは、仮説への賛成ではない。次の事実である。

- 最近、実際に動画を作ろうとしたか
- 何を伝えようとしていたか
- どの工程まで進み、どこで止まったか
- 代わりに何を使い、どれだけ時間や費用をかけたか
- なぜ今も解決していないか
- 有償で次へ進む前に、何を証拠として確認したいか

## 参加条件

次の条件をすべて満たす人を優先する。

1. 自分の経験、知識、物語、企画、価値観のいずれかを動画にしたい
2. 副業として発信し、実際の反応を確かめたい
3. 具体的なテーマが一つ以上ある
4. 最近、制作、調査、外注検討、サービス比較など何らかの行動をした
5. 制作負荷によって完成または公開が止まった経験がある

今回の対象に含めない。

- 小規模ビジネスの商品販売や集客が主目的
- 動画にしたい具体的なテーマがない
- 無料のAI体験だけに興味がある
- 収益、再生数、成功の保証を前提にする
- 権利侵害、無断転載、低品質な大量投稿を目的にする

## 募集の割り振り

最初の5人を一つの場所だけから集めない。

| 枠 | 探す場所 | 目的 |
|----|----------|------|
| 1〜2 | 既知の知人、友人、元同僚 | 率直な行動履歴を深く聞く |
| 3〜4 | 副業、動画発信、創作に関する既存コミュニティ | 知人以外でも同じ障壁があるか確認する |
| 5 | SNSまたは紹介 | 新しい接点でも対象条件が伝わるか確認する |

同じ人物を複数枠へ数えない。個人名、連絡先、所属先はこのリポジトリへ記録しない。

## 個別に送る募集文

```text
いま、自分の経験や知識、物語など「伝えたいこと」を動画にしたいけれど、制作の途中で止まったことがある方へ、25〜30分ほどお話を聞いています。

商品を売る面談ではなく、実際に何を作ろうとして、どこで難しくなったのかを知るための聞き取りです。

もしご自身に近ければ、お話を聞かせてもらえないでしょうか。答えたくない質問は飛ばせます。内容は個人が特定されない形で共通点だけをまとめます。
```

## 公開で募集する文

```text
「自分の想いを動画にしたい」と思って、実際に作ろうとしたものの、途中で止まった経験がある方を探しています。

経験、知識、物語、企画など、動画にしたかった内容は問いません。副業として発信や反応検証を考えている方へ、25〜30分ほど、実際に起きたことを聞かせてください。

販売ではありません。個人が特定される情報は公開せず、答えたくない質問は飛ばせます。
```

## 面談前の確認

日程を確定する前に、次の5問へ短く答えてもらう。

1. `どんな内容を動画にしたいと思いましたか？`
2. `副業として発信や反応検証を考えていますか？`
3. `実際に何か行動しましたか？`
4. `どの段階で止まりましたか？`
5. `25〜30分の聞き取りに参加できますか？`

回答は参加条件の確認だけに使う。詳しい想いや個人情報を公開コメントへ書かせない。

## 30分の進め方

| 時間 | 内容 |
|------|------|
| 0〜3分 | 販売ではないこと、匿名集計、録音の有無、質問を飛ばせることを確認 |
| 3〜15分 | 最後に動画を作ろうとした具体的な出来事と行動を聞く |
| 15〜22分 | 停止した工程、代替手段、時間、費用、優先度を聞く |
| 22〜27分 | 有償で進む前に必要な証拠、条件、懸念を聞く |
| 27〜30分 | 要約を本人へ返し、誤解がないか確認。必要なら次回連絡の許可を別に取る |

質問本文は `marketing/SNS/customer-interview-guide.md` を使う。`PRF-001` は公開可能な実例になっていないため、今回の面談では見せない。

## 5人後の判断

これは初期の判断基準であり、市場全体の割合を主張するものではない。

### 続行

- 3人以上に、最近の制作行動と共通する停止点がある
- 2人以上に、過去の実支出、重い手作業、外注検討など具体的な負担がある
- 2人以上が、必要な証拠を示した上で有償導入の次回相談を検討する

### 修正

- 想いを動画にしたい行動はあるが、停止点や必要な提供内容が分かれる
- この場合、ペルソナや顧客属性をすぐ変えず、用途、証拠、提供範囲の一要素だけを変えて追加面談する

### 中止または保留

- 最近の制作行動がほとんどない
- 無料利用や収益保証への関心だけで、制作問題の優先度が低い
- 現行 ToC が安全に提供できる範囲と、求められる成果が一致しない

判断と匿名集計は `marketing/SNS/gtm-learning-log.md` へ記録する。
