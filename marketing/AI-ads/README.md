# ToC作品とECの広告制作

作品・商品・誘導先を受け取り、広告の企画、コピー、画像や動画、比較テストの準備へ進めるための実務資料。『そのまま使えるAI×ネット広告』の全5章・52項目を閲覧し、ToCとEC向けの独自の制作手順として整えた。

## 次回の依頼

細かいプロンプトを作らず、次のように頼めばよい。

> このToC作品から、Instagram用の15秒広告を3案作って。本編の視聴につなげたい。素材はこのrun。

> この商品ページと商品写真で、EC用の広告画像と30秒動画を作って。まずは購入を検証したい。

> この広告の実績を見て、次に試すコピーと冒頭映像を作って。

スキル名は `ai-ad-creative`。明示する場合は `$ai-ad-creative` と依頼する。スキル一覧に出ない環境では、このファイルを読ませれば同じ資料へ進める。

## 対象を最初に分ける

| 対象 | 成功の定義 | 最初に読む材料 |
| --- | --- | --- |
| ToCで作った作品 | 本編の視聴など、指定された行動 | 完成映像、作品情報、公開先、既存の反応 |
| ToCサービス | 適合する相談・導入につながること | [ToC方針](../README.md)、[商品と提供範囲](../first-offer.md) |
| EC商品 | 注文・利益など、指定された事業成果 | 商品ページ、現物写真、価格・送料・返品条件、原価、実績 |

制作物ができたことと広告効果が確認できたことは別の状態として記録する。今回整備したのは制作の準備であり、広告配信や成果の検証はまだ行っていない。

## 別チャットでの引き継ぎ

この環境の個人スキルとして登録しているので、この会話の履歴を渡す必要はない。次のチャットで対象と希望を伝え、`$ai-ad-creative` を指定すれば、必要な判断資料を読み分ける。

別の端末やファイルにアクセスできない環境では、このスキルと参照資料も渡す必要がある。スキルはモデル自体へ恒久的に知識を学習させるものではない。通常の制作に必要な判断はローカルに保存しているが、書籍の本文や付属ボットの複製は含まない。
