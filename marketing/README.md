# ToC マーケティングガイド

更新日: 2026-08-29

`marketing/` は、ToC を必要とする副業に取り組む個人と小規模ビジネス運営者へ届け、利用開始、継続、収益化の検証またはビジネス価値の伝達へ接続するための正本を置く。

## 最上位の方針

### 存在目的

`人の心を動かし、人生を豊かにする。`

これは ToC が存在する理由であり、生成本数、速度、売上より上位に置く。収益は、人へ届けた価値を継続可能にする対価として扱う。

### 顧客に最初に伝える言葉

`あなたの想いを、映像に。`

この一文は、共通サイトなどで訪問者が最初に受け取る入口である。`世界に増やす` のような ToC 側の願望を先に置かず、訪問者の知識、物語、経験、世界観が映像になる未来を主語にする。

詳しい説明は次の順で加える。

| 理解の目安 | 役割 | 伝える内容 |
|------------|------|---------|
| 0 秒 | 直感的な入口 | `あなたの想いを、映像に。` |
| 3 秒 | 制作できる範囲 | `一枚の画像から、一本の動画まで。` |
| 10 秒 | 実現方法 | `企画、構成、画像、動画、音声、編集を、ひとつの制作の流れへ。` |

`0 秒` は内部の設計概念であり、外部向けの脳科学的主張には使わない。理解テストを行う場合は 1 秒 / 3 秒 / 10 秒で確認する。

### 立ち位置

ToC は、副業に取り組む個人と小規模ビジネス運営者が、必要な画像をまとめて生成し、動画まで一つの流れで継続制作するための AI ビジュアル制作システムである。

提供能力は次の2つに分ける。

| 制作形式 | 内部識別名 | 提供するもの |
|----------|------------|--------------|
| 画像一括生成 | `image_batch` | 必要な画像をまとめて生成 |
| 動画制作 | `video` | 構成・画像・映像・音声・編集まで完成 |

同じ企画や素材を次の制作へ再利用できることは、第三の制作形式ではなく、2つに共通する強みとして扱う。

```text
速いから試せる。
簡単だから続けられる。
続けられるから、副業の仮説を検証し、ビジネスの価値を画像・動画資産として蓄積できる。
```

### 機能面の約束

`画像も動画も、もっと速く、もっと簡単に。`

比較可能な実測が揃った場合だけ、実測で裏づけられた表現として `画像・動画制作を、圧倒的に速く、簡単に。` を使う。比較には所要時間、人間の実作業時間、担当工程、生成・採用点数、完成物、外部 AI サービスの利用料を含める。

### 画像一括生成の約束

通常の公開表現:

`あなたの世界観に合う画像を、まとめて。`

ToC は、顧客が大切にしたい色、空気感、光、質感、構図、避けたい表現を見た目の基準へ変え、その世界観に合う複数の画像をまとめて生成できる。目的、視聴者、再利用素材、場面、別案、保存先、品質確認も一つの設計へまとめる。`大量生成` を公開表現にする場合は、依頼点数だけでなく、生成点数、採用点数、採用率、全体の所要時間、人間の実作業時間、外部 AI サービスの利用料、修正回数、生成元と保存先を追える記録を同じ実例で示す。

画像数だけを増やす低品質な大量生成は価値にしない。必要な画像を、用途と一貫性を保ちながら生成・選択・再利用できることを強みにする。

### 感情面の約束

`作りたいと思った瞬間を、完成まで止めない。`

### ToC が必要な理由

一般的な AI ビジュアル制作では、人間が企画、構成、画像生成、動画生成、音声、編集のサービスを行き来する。ToC は、再利用する素材、多数の画像、一本の動画を同じ制作意図から一つの流れとして組み立て、人間が目的、品質、採用、公開判断へ集中できるようにする。

神話、民話、物語は ToC の商品テーマではない。制作能力を検証し、長尺作品も作れることを示す実例の一分類として扱う。

## 提供形態と料金の事実

ToC は月額利用型のサービスではなく、顧客が自分の環境で画像・動画制作を続けられるように、ビジュアル制作システム一式を納品するサービスである。

| 項目 | 公開時の扱い |
|------|--------------|
| ToC 導入費 | 最初の商品は `先着30名限定｜導入協力価格29,800円（税込）`。31名目以降は `59,800円（税込）`。その他の商品は金額確定まで `個別見積り` |
| ToC 月額料金 | `0円`。システム利用権に継続課金しない |
| 外部サービス料金 | 別途必要。利用する AI・クラウドサービスの使用量に応じて顧客が負担する |
| 保守・更新・運用代行 | 納品費に自動で含めない。必要な場合は範囲と料金を別契約で明示する |

`月額0円` だけを単独で強調して無料サービスと誤認させない。必ず `システム納品後の ToC 月額料金` であることと、`外部 AI・クラウドサービスの料金は別途` を近接表示する。

## 主な顧客層

### A. 副業に取り組む個人

- 本業や生活と両立しながら、限られた時間と予算で最初の画像セットまたは動画を完成させたい
- 編集スキル、ツール過多、外注費、継続できない不安が障壁
- 欲しい結果は、反応を検証できる画像・動画コンテンツと継続可能な収益の種
- 感情遷移は `難しそう -> 自分にも作れそう -> まず1本試したい`
- 主な行動ボタンは `副業の最初のコンテンツを作る`

### B. 小規模ビジネス運営者

- 事業主、運営責任者、または少人数チームとして、集客、サービス説明、顧客教育、採用、信頼形成に画像と動画を使いたい
- 専任のビジュアル制作機能がなく、制作時間、外注の不統一、費用、継続停止が障壁
- 欲しい結果は、事業の価値を一貫して伝え、繰り返し改善・再利用できる画像・動画資産
- 感情遷移は `必要だが作れない -> 自社でも形にできそう -> 続けられる -> 事業に蓄積できる`
- 主な行動ボタンは `ビジネスの画像・動画制作を設計する`

2つの顧客層を同一の広告や紹介ページへまとめない。共通サイトでは `副業を試す` と `ビジネスを伝える` で分岐させ、広告は顧客層別の紹介ページへ直接送る。

`個人ブランド` は主な顧客層ではなく、専門家、コンサルタント、コーチ、クリエイターなど、運営者本人の知識と信用が事業価値になる小規模ビジネスの利用例として扱う。

### 最初に販売する相手

最初の販売・集客は、`副業に取り組む個人 × 動画制作` に集中する。

その中で最初に深く届ける顧客像は、次の一人とする。

`自分の知識や経験を、自分の世界観に合う画像で動画にしたい副業個人`

これは副業に取り組む個人全体を狭める定義ではない。広い顧客層の中から、最初の広告、紹介ページ、実例、商談を一人分の切実な状況へ合わせるための顧客像である。

顧客へ最初に届ける言葉の案:

`あなたの世界観に合う画像で、知識と経験を動画に。`

最初に解消する問題は、`人に伝えられる知識や経験はあるが、自分の世界観に合う画像を作れず、複数の制作工程も負担になって、一本の動画を完成・公開できていない` ことである。最初の提供では、顧客のブランドや世界観に合う画像を生成し、その画像で知識や経験を動画へ仕上げる。

最初の商品案:

`あなたの世界観に合う画像で、知識と経験を動画に。`

顧客のブランドや世界観を、色、空気感、光、質感、構図、避けたい表現まで含めて整理する。その基準に合う画像を生成し、動画へ仕上げる。詳しい範囲は `marketing/first-offer.md` を正本とする。

最初の価格は `先着30名限定｜導入協力価格29,800円（税込）` とする。31名目以降は59,800円（税込）へ切り替える。問い合わせ数ではなく、適合条件の確認後に契約と支払い手続きが完了した順で数える。

価格を外注費と比較する場合は、`動画編集を1本10,000円で3本外注すると30,000円` という仮定を明記し、`3本分の編集外注費で、あなたの世界観に合う画像と動画を。` と伝える。外部サービス利用料、顧客の作業時間、副業収益の保証は含まない。

小規模ビジネス運営者は次の販売市場として保持する。画像一括生成も正式な提供能力として保持し、最初の動画に必要な画像制作や、今後の単独商品として検証する。

## 直感を優先する設計ルール

内部で使う `右脳設計` は、外部向けの脳科学的主張ではない。説明を読む前に訪問者が変化を理解し、自分の企画が動き出す可能性を感じるための設計上の略称である。

| 原則 | 実務ルール |
|------|------------|
| 主語は訪問者の未来 | AI や外部サービスより、作れる・続けられる・育てられるを先に置く |
| 説明より変化 | 機能一覧より、一行のテーマが画像セットまたは完成動画へ進む様子を見せる |
| 速さより解放 | 秒数だけでなく、制作の重さから解放される感覚を作る |
| 簡単さより自己効力感 | `初心者向け` ではなく `自分にも完成させられる` を渡す |
| 行動は自分で選べる | 副業か小規模ビジネスか、何を作りたいかを訪問者が選ぶ |
| 感情と操作を分ける | 偽の希少性、収益保証、恐怖、誇大な実績を使わない |

## 利用までの流れ

```text
Meta / YouTube / SNS / 検索
  -> 顧客層別の紹介ページ、または共通サイト
  -> 作りたい画像・動画を一行で入力
  -> サイト内フォーム / 相談 / 導入案内
  -> 最初の画像セット、または動画
  -> 継続制作
  -> 副業の反応検証、または再利用できるビジネス用素材の蓄積
```

- Meta 広告は副業向けと小規模ビジネス向けを分ける
- YouTube / SNS は ToC の画像・動画完成物、制作過程、一括生成、速さ、簡単さを証明する
- 公開サイトは、立ち位置、比較、実例、問い合わせまでの導線の正本とする
- フォームはサイト内に実装し、入力した画像・動画テーマと希望する制作形式を引き継ぐ
- Notion / Google Forms は正式な受付経路にしない

## 言葉のルール

- ユーザー向けの説明と公開文章は、分かりやすい日本語を基本にする
- 英語の専門用語や内部識別名を、そのまま説明の途中へ入れない
- 専門概念が必要な場合は、最初に意味を日本語で一文説明してから使う
- 生成経路を説明する場合は、`どの依頼から生成され、どこに保存されたかを追える記録` と書く
- 公開できるか未確認の資料は、`公開前の参考材料` と書く
- 提供内容をこれから検証する段階では、`提供内容の仮説` と書く
- 信頼を支える材料は、文脈に応じて `実例`、`根拠`、`証拠` と書く
- 作れるものの違いは `制作形式`、スレッド間で渡す内容は `引き継ぎ` と書く
- API、SNS、URL など一般に定着した略語は使用できるが、必要に応じて意味を補足する

## 適用範囲

このマーケティング方針は、公開サイト、紹介ページ、広告導線、SNS配信、見込み顧客の獲得、反応分析、改善に適用する。通常の ToC の調査、物語、台本、画像、ナレーション、動画生成の制作仕様へ流用しない。

## フォルダ構成

```text
marketing/
├── README.md
├── go-to-market.md
├── positioning-and-offer.md
├── first-offer.md
├── browser-use.md
├── LP/
├── SEO/
└── SNS/
```

- `LP/`: 独立した公開サイト、共通の紹介ページ、顧客層別の紹介ページ、サイト内フォームの正本
- `SNS/`: 公開サイトへ案内し、ToC の価値を実例で示す各配信先の正本
- `SEO/`: 検索順位の測定、1回1キーワードの改善、7日観察と効果判定の運用手順
- `go-to-market.md`: 複数スレッドで販売準備・問い合わせ獲得・反応分析を並行するための分担
- `positioning-and-offer.md`: スレッド1が管理する対象顧客、提供内容の仮説、商談対象の条件、下流への引き継ぎの正本
- `first-offer.md`: 最初の顧客像へ販売する商品、納品物、役割分担、価格決定条件の正本
- `browser-use.md`: 管理画面操作が必要なマーケティング作業の共通ガイド
