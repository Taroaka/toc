# ToC marketing personas and message contract

更新日: 2026-07-19

用途: ToC public site、persona-specific LP、広告、フォーム、proof 制作で使う audience / message の正本。

## 0. Persona policy

ToC の persona は年齢、性別、居住地のような demographic ではなく、`動画を作りたい理由`、`現在止まっている場所`、`利用後に得たい変化` で定義する。

固定事項:

- primary audience は個人
- primary personas は `side_business` と `personal_brand`
- 同じ広告、Hero、LP、CTAへ混ぜない
- ToC の機能より visitor の未来を先に見せる
- 収益、再生数、ブランド成長を保証しない
- 神話・民話は persona ではなく proof category

検証が必要な仮説:

- persona ごとの実際の利用可能時間
- 現在支払っている外注費 / tool cost
- first-video experience へ支払える価格
- long-form と short-form の優先順位
- self-service、guided、done-for-you の希望比率
- first video から second video へ進む条件

## 1. Persona A: side_business

### Internal name

`本業後の限られた時間で、動画副業を試したい人`

### Situation

- 本業や家事の後に使える時間が限られている
- YouTube、Shorts、Reels、TikTok などに収益機会を感じている
- niche や企画の候補はある、または探している
- 動画制作の全工程を学んでから始める余裕はない
- 外注へ大きく投資する前に、小さく反応を確かめたい
- tutorial や tool 紹介を見るほど、選択肢が増えて止まりやすい

年齢、性別、職種は targeting の必須条件にしない。`本業以外の収益を作りたいが、制作負担で開始できていない` 行動状態を優先する。

### Jobs to be done

```text
本業以外の収益につながる動画企画を思いついたとき、
動画制作一式を習得したり、高額な外注をしたりせず、
公開できる最初の1本へ変えたい。
そうすれば、思いつきのまま抱えず、実際の反応で続ける価値を判断できる。
```

### Progress sought

The user is not initially buying `AI agents`. The user is buying:

1. 開始できること
2. 最初の1本が完成すること
3. 小さく市場反応を試せること
4. 次の1本へ改善を引き継げること
5. 続けるか止めるかを実データで判断できること

### Current alternatives

- tutorial を見ながら編集ソフトを自習する
- ChatGPT、画像生成、動画生成、TTS、編集を個別に操作する
- テンプレート動画を量産するサービスを使う
- freelancer / agency に外注する
- 企画だけ保存し、制作しない

The strongest competitor is often `何も公開しないまま先送りすること`.

### Functional pains

- 何をどの順番で作ればよいか分からない
- tool ごとに prompt と設定を作り直す
- 素材、version、音声、尺の管理が難しい
- 仕事後に編集へ集中する時間が残らない
- 1本作って疲れ、継続できない
- 外注前に企画の当たり外れを確認できない

### Emotional pains

- 始めたいのに何も完成していない焦り
- AI時代に取り残される感覚
- 失敗して時間と費用を無駄にする不安
- `自分には動画制作は無理` という自己評価
- 周囲に話した副業を始められていない気まずさ

Do not amplify fear. Show a credible first step and realistic boundary.

### Desired identity

```text
動画制作を勉強している人
  -> 自分の企画を公開して検証できる人
  -> 改善しながら小さな事業を育てられる人
```

### Emotional transition

| Moment | Before | Site must create | Evidence |
|--------|--------|------------------|----------|
| ad / first view | 面倒、難しそう | `これなら始められるかもしれない` | one-line idea -> completed output |
| consideration | 本当に簡単か疑う | `必要な判断だけすればよい` | ToC-owned / human-owned stage split |
| risk review | お金と時間が無駄にならないか | `まず1本で検証できる` | real elapsed time, human time, provider cost |
| action | 何を入力すればよいか不安 | `自分の案を書くだけでよい` | concrete idea examples |
| after first video | 続けられるか不安 | `次は改善して作れる` | retained brief, reusable series structure |

### Message ladder

#### Identity outcome

`動画を作れる人になり、副業のアイデアを実際に試せる。`

#### Emotional benefit

`作れないまま時間だけが過ぎる状態から抜け出せる。`

#### Functional benefit

`企画、台本、映像、音声、編集を一つの制作フローで進められる。`

#### Mechanism

`一行のテーマを起点に、ToC が必要な制作工程を組み立てる。`

### Copy contract

Hero:

```text
動画副業を、
「作れない」で終わらせない。
```

Subcopy:

```text
本業のあとに、複数の生成AIや編集ソフトと格闘しなくていい。
テーマを伝えたら、ToC が最初の1本までの制作工程をつなぎます。
```

Primary CTA: `副業の最初の1本を作る`

CTA destination expectation: すぐに決済させるのではなく、動画テーマを一行で入力する。

### High-intent triggers

- niche / channel idea をすでに持っている
- 動画制作を試したが編集または tool chain で止まった
- 外注見積もりが想定より高かった
- 投稿頻度を維持できなかった
- AI動画の情報収集を続けているが、まだ公開していない

### Required proof

1. novice-equivalent brief から完成した動画
2. input から output までの全 boundary
3. elapsed time と active human time
4. 使用した外部 provider cost
5. human review / revision count
6. 同じ brief から short / long へ展開した例
7. 2本目で再利用できた設計と素材

### Objections and answers

| Objection | Hidden concern | Answer direction | Required evidence |
|-----------|----------------|------------------|-------------------|
| 編集経験がない | 自分だけ使いこなせない | tool 操作より目的、視聴者、テーマから始める | first-time flow |
| 何を作ればよいか分からない | niche 選びで失敗したくない | audience / problem / outcome を brief にする | idea examples |
| AI動画は低品質 | 公開して恥をかきたくない | human approval と品質 gate を見せる | before / after review |
| 本当に稼げるか | 投資回収が不安 | 収益を保証せず、低い制作負担で検証回数を増やす | cost / test case |
| 続けられない | また三日坊主になる | 2本目に brief と素材を再利用する | repeat creation proof |
| 費用が読めない | provider 課金が膨らむ | fixed / variable cost を分けて表示する | itemized cost |

### Disqualifiers

- 確実な収益や再生数を保証してほしい
- 内容や品質を一度も判断せず完全放置したい
- platform rule、権利、広告表示を無視したい
- low-quality mass spam が目的

Do not optimize the LP to acquire these leads.

### Persona-specific form questions

Ask no more than two before contact details.

- `side_business_stage`: アイデアだけ / 制作途中 / 公開経験あり / 継続中
- `side_business_goal`: 最初の1本 / niche 検証 / 投稿継続 / 収益化検証

Optional after lead submission:

- weekly available time
- preferred platform
- current tools / outsourcing

## 2. Persona B: personal_brand

### Internal name

`専門性や世界観はあるが、動画発信を継続できていない人`

### Situation

- 専門知識、経験、思想、作品、サービスのいずれかを持つ
- consultant、coach、teacher、creator、independent professional、small-business owner など、一人の名前と信用が価値になる
- text、presentation、audio、SNS post など既存素材がある場合も多い
- 自分で動画を作ると本業が止まり、外注すると tone がずれる
- 単発の viral video より、一貫した認知と信頼を積み上げたい

職業名より、`自分自身または自分の専門性がブランドの中心である` 状態を優先する。

### Jobs to be done

```text
自分の知識や思想を継続的に発信したいとき、
毎回ゼロから動画を企画・制作したり、自分らしさを外注先へ説明し直したりせず、
一貫した動画シリーズへ変えたい。
そうすれば、本業へ集中しながら、動画が自分の信用と認知を蓄積してくれる。
```

### Progress sought

The user is buying:

1. 頭の中の価値を見える形にすること
2. 自分らしさを失わず動画へ展開すること
3. 発信を単発で終わらせないこと
4. 動画を検索・共有・再利用できる資産にすること
5. 名前と専門領域の結びつきを強くすること

### Current alternatives

- 自分で話してスマートフォン撮影する
- SNS post や newsletter だけを続ける
- editor / agency へ単発で外注する
- generic template / avatar video service を使う
- 発信を後回しにして referral だけに頼る

The strongest competitor is `本業が忙しいので発信は後でよい`.

### Functional pains

- idea はあるが構成と制作へ移せない
- 撮影、編集、確認が本業を圧迫する
- 外注先が変わるたびに tone と品質が変わる
- 過去の文章、講義、音声を動画へ再利用できない
- channel ごとに format を作り直す
- series rules がなく、投稿が蓄積して見えない

### Emotional pains

- 実力や価値が外から見えないもどかしさ
- 発信力のある競合だけが認識される焦り
- generic AI 表現で自分らしさが薄まる不安
- 中途半端な動画を公開して信用を落とす恐れ
- `何者として知られたいか` が定まらない不安

### Desired identity

```text
専門性はあるが発信できていない人
  -> 自分の考えを継続的に届けられる人
  -> この分野ならこの人、と想起される人
```

### Emotional transition

| Moment | Before | Site must create | Evidence |
|--------|--------|------------------|----------|
| ad / first view | 自分の価値が伝わっていない | `これなら自分の世界観を形にできる` | one expertise -> coherent series visual |
| consideration | AIで個性が消えそう | `自分らしさを正本として守れる` | brand brief and consistent outputs |
| risk review | 品質で信用を落としたくない | `人間が公開判断できる` | approval and revision evidence |
| action | 何を渡せばよいか分からない | `既存の文章や話したいテーマから始められる` | input examples |
| after first video | 単発で終わりそう | `series として蓄積できる` | 3-video series and reuse proof |

### Message ladder

#### Identity outcome

`知識や世界観を発信し続け、この分野ならこの人という認知を作る。`

#### Emotional benefit

`価値が伝わらないもどかしさから、自分らしく見せられる確信へ変わる。`

#### Functional benefit

`brand brief と series rules を保ちながら、動画制作を継続できる。`

#### Mechanism

`ToC が既存素材やテーマを制作フローへ入れ、人間の承認を通して動画へ展開する。`

### Copy contract

Hero:

```text
頭の中にあるものを、
発信できるブランドへ。
```

Subcopy:

```text
あなたの知識、経験、思想、世界観を、
自分らしさを保ったまま、続けられる動画シリーズに変えます。
```

Primary CTA: `自分のブランド動画を設計する`

CTA destination expectation: expertise / audience / desired perception を入力し、brand-video brief を始める。

### High-intent triggers

- text / audio / seminar assets が蓄積している
- 発信カレンダーが止まっている
- editor や agency の output が自分らしくない
- service launch、book、course、event など公開予定がある
- 自分の名前で集客する必要性が高まった
- 一つの動画を複数 channel へ展開したい

### Required proof

1. one brand brief from which 3 coherent videos were made
2. input material -> script -> output traceability
3. tone, vocabulary, visual, prohibited-expression rules
4. consistency across long-form and short-form
5. human approval and revision record
6. reuse of existing text / slide / audio
7. before / after of fragmented posts versus coherent series

### Objections and answers

| Objection | Hidden concern | Answer direction | Required evidence |
|-----------|----------------|------------------|-------------------|
| AIで個性が消える | 誰と同じでもない自分でいたい | brand brief を generation より上位に置く | distinct brand examples |
| 品質が信用に足りない | 低品質公開で評判を落としたくない | human approval、revision、非公開 preview | approval flow |
| 自分で話す方が早い | 仕組み導入が逆に負担かもしれない | face、voice、faceless、existing asset reuse を選べる | format comparison |
| 外注で十分 | ToC の固有価値が分からない | 毎回説明し直さず、series rules と assets が蓄積する | second / third video proof |
| 継続できるか | 一度だけの制作で終わる不安 | cadence と repeatable format を最初に設計する | content system example |
| 自分のテーマが狭い | ネタ切れが不安 | expertise を audience questions / beliefs / cases へ分解する | topic map |

### Disqualifiers

- 自分の立場、主張、対象者を一切決めたくない
- brand consistency より短期的な spam volume だけを求める
- 公開判断と事実確認を完全に放棄したい
- 他者の人格、声、著作物を無断で模倣したい

### Persona-specific form questions

Ask no more than two before contact details.

- `expertise_topic`: 何について知られる人になりたいですか？
- `brand_video_goal`: 認知 / 信頼 / 問い合わせ / 教育 / launch support

Optional after lead submission:

- existing assets
- desired publishing cadence
- face / voice / faceless preference
- current channel URLs

## 3. Shared persona boundary

| Decision | side_business | personal_brand |
|----------|---------------|----------------|
| first desired outcome | market test | consistent recognition |
| first fear | time / money wasted | identity / trust damaged |
| proof that matters | completion time, effort, cost | consistency, approval, reuse |
| language | 最初の1本、試す、改善する | 自分らしさ、蓄積、series、信用 |
| CTA | 副業の最初の1本を作る | 自分のブランド動画を設計する |
| landing visual | after-work idea becomes published video | scattered expertise becomes coherent series |
| success beyond lead | first video completed | brand brief + first series completed |

Do not use `副業もブランドも` in the same ad headline. Do not change persona after the click unless the visitor explicitly selects another path.

## 4. Public-site routing

Common home question:

`動画を作った先に、何を育てたいですか？`

Options:

- `副業の可能性を試したい`
- `自分のブランドを育てたい`

Avoid `あなたはどのタイプですか？`. Ask about desired progress, not identity labels.

## 5. Proof production backlog

Before paid acquisition, produce at minimum:

### Side-business proof

- one realistic niche explainer or discovery video
- one short-form derivative
- transparent time / cost / revision record
- a second-video reuse example

### Personal-brand proof

- one real expertise brief
- a coherent 3-video set
- long / short derivative
- brand brief, approval, and consistency evidence

The mythology test may remain in `/examples`, but it cannot substitute for either persona proof.

## 6. Research plan

This document is a decision hypothesis until validated.

For each persona, interview at least five people who match the behavioral condition. Ask about the last real attempt, not general opinions.

Questions:

1. 最後に動画を作ろうとしたのはいつか
2. 何を作ろうとして、どこで止まったか
3. そのとき使った時間、tool、外注、費用は何か
4. 完成しなかったことで何を失ったか
5. 何が見えれば新しい制作方法を信用できるか
6. 最初の1本のあと、何があれば次も作るか
7. self-service / guided / done-for-you のどれを選ぶか、なぜか

Update persona assumptions only from repeated patterns. Keep individual anecdotes in research notes, not in this canonical contract.
