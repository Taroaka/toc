# ToC marketing personas and message contract

更新日: 2026-08-29

用途: ToC public site、persona-specific LP、広告、フォーム、proof 制作で使う audience / message の正本。

## 0. Persona policy

ToC の顧客層は年齢、性別、居住地ではなく、`画像・動画を作りたい理由`、`現在止まっている場所`、`利用後に得たい変化` で定義する。

固定事項:

- 主な顧客層は `side_business` と `small_business`
- 最初の販売対象は `side_business × video`
- 最初に深く届ける顧客像は `自分の知識や経験を、自分の世界観に合う画像で動画にしたい副業個人`
- 最初の商品価値は `顧客の世界観に合う画像と動画を作ること`
- `personal_brand` は独立した顧客層ではなく、`small_business` の利用例
- 同じ広告、Hero、LP、CTAへ混ぜない
- ToC の機能より visitor の未来を先に見せる
- 収益、再生数、ブランド成長を保証しない
- 神話・民話は persona ではなく proof category

Shared brand layer:

- Purpose: `人の心を動かし、人生を豊かにする。`
- common brand line: `あなたの想いを、映像に。`
- common brand line はブランド共通の 0 秒入口であり、persona-specific Hero、subcopy、CTA を置き換えない

検証が必要な仮説:

- persona ごとの実際の利用可能時間
- 現在支払っている外注費 / tool cost
- 導入協力価格29,800円を、納品内容に見合うと判断する条件
- long-form と short-form の優先順位
- self-service、guided、done-for-you の希望比率
- first video から second video へ進む条件

## 1. Persona A: side_business

### Internal name

`人へ伝えられる知識や経験はあるが、自分の世界観に合う画像を作れず、動画発信を始められていない人`

これは副業に取り組む個人全体を狭める定義ではなく、最初の商品ページ、実例、相談を一人分の切実な状況へ合わせるための顧客像である。

### Situation

- 本業や家事の後に使える時間が限られている
- YouTube、Shorts、Reels、TikTok などに収益機会を感じている
- niche や企画の候補はある、または探している
- 自分の仕事、生活、学習から得た知識や経験がある
- 生成した画像がありきたりで、自分のブランドや世界観に合わない
- 自分らしさが伝わる画像と動画を作りたい
- 動画制作の全工程を学んでから始める余裕はない
- 外注へ大きく投資する前に、小さく反応を確かめたい
- tutorial や tool 紹介を見るほど、選択肢が増えて止まりやすい

年齢、性別、職種は targeting の必須条件にしない。`本業以外の収益を作りたいが、制作負担で開始できていない` 行動状態を優先する。

### Jobs to be done

```text
人へ伝えられる知識や経験を副業の動画にしたいとき、
ありきたりなAI画像で自分らしさを失わず、
動画制作一式を習得したり、高額な外注をしたりせず、
公開できる最初の1本へ変えたい。
そうすれば、思いつきのまま抱えず、実際の反応で続ける価値を判断できる。
```

### Progress sought

The user is not initially buying `AI agents`. The user is buying:

1. 開始できること
2. 自分の世界観に合う画像と最初の1本が完成すること
3. 自分らしさを画像と動画で伝えられること
4. 小さく市場反応を試せること
5. 採用画像と世界観の基準を手元に残せること

### Current alternatives

- tutorial を見ながら編集ソフトを自習する
- ChatGPT、画像生成、動画生成、TTS、編集を個別に操作する
- テンプレート動画を量産するサービスを使う
- freelancer / agency に外注する
- 企画だけ保存し、制作しない

The strongest competitor is often `何も公開しないまま先送りすること`.

### Functional pains

- 何をどの順番で作ればよいか分からない
- tool ごとに prompt と設定を作り直す
- 素材、version、音声、尺の管理が難しい
- 仕事後に編集へ集中する時間が残らない
- 1本作って疲れ、継続できない
- 外注前に企画の当たり外れを確認できない
- 生成画像がありきたりで、自分の発信に見えない

### Emotional pains

- 始めたいのに何も完成していない焦り
- AI時代に取り残される感覚
- 失敗して時間と費用を無駄にする不安
- `自分には動画制作は無理` という自己評価
- AIで作ると自分らしさが失われる不安
- 周囲に話した副業を始められていない気まずさ

Do not amplify fear. Show a credible first step and realistic boundary.

### Desired identity

```text
動画制作を勉強している人
  -> 自分らしい世界観で知識や経験を届けられる人
  -> 改善しながら小さな事業を育てられる人
```

### Emotional transition

| Moment | Before | Site must create | Evidence |
|--------|--------|------------------|----------|
| ad / first view | AI画像が自分らしくない | `自分の世界観に合う画像と動画を作れる` | 世界観の基準 -> 画像群 -> 完成動画 |
| consideration | AIでは自分らしさが消えそう | `見た目を自分で採用できる` | 代表画像と採用・不採用理由 |
| risk review | お金と時間が無駄にならないか | `まず1本で検証できる` | real elapsed time, human time, provider cost |
| action | 何を入力すればよいか不安 | `自分の案を書くだけでよい` | concrete idea examples |
| after first video | 続けられるか不安 | `次は改善して作れる` | retained brief, reusable series structure |

### Message ladder

#### Identity outcome

`自分らしい世界観の画像と動画で、知識や経験を届けられる。`

#### Emotional benefit

`ありきたりな見た目で止まる状態から抜け出せる。`

#### Functional benefit

`世界観の基準、画像、構成、映像、音声、編集を一つの制作の流れで進められる。`

#### Mechanism

`知識や経験と、色、空気感、光、質感、構図、避けたい表現を起点に、ToC が世界観に合う画像と動画を組み立てる。`

### Copy contract

Hero:

```text
あなたの世界観に合う
画像と動画を。
```

Subcopy:

```text
色、空気感、光、質感、構図まで。
あなたらしい画像を作り、一本の動画まで仕上げます。
```

Primary CTA: `自分の世界観で動画を作る`

CTA destination expectation: すぐに決済させるのではなく、動画テーマを一行で入力する。

### High-intent triggers

- niche / channel idea をすでに持っている
- 動画制作を試したが編集または tool chain で止まった
- 外注見積もりが想定より高かった
- 投稿頻度を維持できなかった
- AI動画の情報収集を続けているが、まだ公開していない
- 生成画像を試したが、自分の世界観に合わなかった

### Required proof

1. 実在する知識・経験と、届けたい相手
2. 顧客が採用した世界観の基準
3. 同じ基準に合う代表画像と各場面の採用画像
4. その画像で作った完成動画
5. 採用画像と不採用画像、その判断理由
6. input から output までの全 boundary
7. elapsed time、active human time、外部 provider cost、revision count
8. 2本目で再利用できた世界観の基準、設定、素材

### Objections and answers

| Objection | Hidden concern | Answer direction | Required evidence |
|-----------|----------------|------------------|-------------------|
| 編集経験がない | 自分だけ使いこなせない | tool 操作より目的、視聴者、テーマから始める | first-time flow |
| AI画像が自分らしくない | 他と同じ見た目になりたくない | 世界観を見た目の基準へ変え、代表画像を先に採用する | 基準、候補、採用理由 |
| 何を作ればよいか分からない | niche 選びで失敗したくない | audience / problem / outcome を brief にする | idea examples |
| AI動画は低品質 | 公開して恥をかきたくない | human approval と品質 gate を見せる | before / after review |
| 本当に稼げるか | 投資回収が不安 | 収益を保証せず、低い制作負担で検証回数を増やす | cost / test case |
| 続けられない | また三日坊主になる | 2本目に brief と素材を再利用する | repeat creation proof |
| 費用が読めない | provider 課金が膨らむ | fixed / variable cost を分けて表示する | itemized cost |

### Disqualifiers

- 確実な収益や再生数を保証してほしい
- 内容や品質を一度も判断せず完全放置したい
- platform rule、権利、広告表示を無視したい
- low-quality mass spam が目的

Do not optimize the LP to acquire these leads.

### Persona-specific form questions

Ask no more than two before contact details.

- `desired_impression`: どんな印象・世界観で伝えたいですか？
- `reference_image_status`: 参考にしたい画像がある / ない / 相談したい

Optional after lead submission:

- 避けたい表現
- 週に使える時間
- 公開先
- 現在使っている制作サービスや外注

## 2. Persona B: small_business

### Internal name

`専任の制作担当を持たず、事業の価値を画像・動画で伝え続けられていない運営者`

### Situation

- 事業主、運営責任者、または少人数チームとして、集客、説明、教育、採用、信頼形成を担う
- 商品、サービス、専門知識、既存の文章や資料など、伝える材料は持っている
- 画像と動画を必要としているが、専任の制作担当がいない
- 自作では本業が止まり、単発の外注では知識、表現、素材、修正判断が蓄積しない
- 一回の制作より、同じ基準で継続・改善・再利用できる制作能力を求める

従業員数や売上ではなく、`意思決定者と制作目的が近く、専任の制作機能が不足している` 状態を優先する。個人ブランドは、運営者本人の専門性や信用を伝える利用例として含める。

### Jobs to be done

```text
商品、サービス、知識を画像や動画で伝えたいとき、
毎回ゼロから企画・制作したり、外注先へ事業の特徴を説明し直したりせず、
同じ目的と表現基準で継続・改善できる制作能力を自社に持ちたい。
そうすれば、本業へ集中しながら、伝えるための素材と判断を事業へ蓄積できる。
```

### Progress sought

The user is buying:

1. 事業の価値を見れば分かる形にすること
2. 業種や表現に合う公開品質を保つこと
3. 画像・動画制作を単発で終わらせないこと
4. 素材、表現基準、採用判断を再利用できる資産にすること
5. 外注のたびに説明し直す負担を減らすこと

### Current alternatives

- 運営者や社員が都度制作する
- デザインツールや動画編集ソフトのテンプレートを使う
- 制作者や制作会社へ単発で外注する
- 画像生成、動画生成、音声、編集のサービスを個別に使う
- 制作を後回しにし、既存の紹介や文章だけに頼る

最も強い競合は `本業が忙しいので制作は後でよい` という先送りである。

### Functional pains

- 伝える内容はあるが、構成と制作へ移せない
- 画像作成、撮影、編集、確認が本業を圧迫する
- 外注先が変わるたびに表現と品質が変わる
- 過去の文章、資料、画像、音声を再利用できない
- 用途ごとに制作方法と指示を作り直す
- 採用基準が残らず、制作物が資産として蓄積しない

### Emotional pains

- 事業の価値が外から分かりにくいもどかしさ
- 発信を続ける競合だけが選ばれる焦り
- ありきたりな AI 表現で自社らしさが薄まる不安
- 中途半端な画像・動画で信用を落とす恐れ
- 新しい制作システムの導入がかえって負担になる不安

### Desired identity

```text
伝える価値はあるが制作が止まっている事業者
  -> 自社の価値を画像・動画で伝え続けられる事業者
  -> 制作の知識と素材を事業資産として持つ事業者
```

### Emotional transition

| Moment | Before | Site must create | Evidence |
|--------|--------|------------------|----------|
| 広告 / 最初の画面 | 事業の価値が伝わっていない | `これなら自社の内容を形にできる` | 事業上の依頼 -> 画像セットまたは動画 |
| 検討 | AIで自社らしさが消えそう | `表現基準を守れる` | 制作方針と一貫した完成物 |
| 不安の確認 | 品質や導入負担が心配 | `人間が採用・公開を判断できる` | 確認、修正、担当範囲の記録 |
| 行動 | 何を渡せばよいか分からない | `商品、資料、伝えたい内容から始められる` | 入力例 |
| 導入後 | 単発で終わりそう | `素材と判断を次へ使える` | 二回目の制作と再利用の実例 |

### Message ladder

#### Identity outcome

`事業の価値を伝え続け、画像・動画制作を自社の能力として持つ。`

#### Emotional benefit

`価値を形にできない不安から、自社でも伝え続けられる確信へ変わる。`

#### Functional benefit

`ブランドの世界観を見た目の基準へ変え、同じ基準に合う画像・動画制作を継続できる。`

#### Mechanism

`ToC が色、空気感、光、質感、構図、避けたい表現を整理し、既存素材や依頼内容を同じ世界観の画像・動画へ展開する。`

### Copy contract

Hero:

```text
伝えたい事業の価値を、
使い続けられる画像・動画へ。
```

Subcopy:

```text
商品、サービス、知識を、自社の表現基準を保ったまま、
ブランドの世界観に合う、改善・再利用できる画像・動画へ変えます。
```

Primary CTA: `ビジネスの画像・動画制作を設計する`

行動後は、事業目的、届けたい相手、作りたい画像・動画を入力し、制作内容の整理を始める。

### High-intent triggers

- 商品・サービスの公開、改定、販売予定がある
- SNS、ウェブサイト、広告、説明資料に必要な画像が足りない
- 発信や顧客教育の予定が止まっている
- 外注した完成物の表現や品質が揃わない
- 既存の文章、資料、画像、音声を別の制作へ使いたい
- 運営者本人の専門性や信用を継続的に伝えたい

### Required proof

1. 実在する事業上の依頼内容と、ブランドの世界観を表す見た目の基準
2. 依頼内容から完成物までを追える記録
3. 目的、届けたい相手、見た目、禁止表現の基準
4. 複数の画像または長尺・短尺で保たれた一貫性
5. 運営者による採用、修正、公開判断の記録
6. 既存の文章、資料、画像、音声を再利用した実例
7. 二回目の制作で再利用できた素材と判断

### Objections and answers

| Objection | Hidden concern | Answer direction | Required evidence |
|-----------|----------------|------------------|-------------------|
| AIで自社らしさが消える | 他社と同じ表現にしたくない | 事業の目的と表現基準を生成より上位に置く | 異なる事業の実例 |
| 品質が信用に足りない | 公開して評判を落としたくない | 人間の採用判断、修正、非公開確認を示す | 確認の流れ |
| 導入が重そう | 新しい仕組みが本業を圧迫しそう | 顧客と ToC の担当範囲を明示する | 初回導入の実測 |
| 外注で十分 | システムを持つ理由が分からない | 毎回説明し直さず、素材と判断が蓄積する | 二回目の制作実例 |
| 費用が読めない | 導入費と外部料金が膨らみそう | 固定費と使用量に応じる費用を分ける | 費用明細 |
| 自社で続けられるか | 一度だけの制作で終わりそう | 次回の始め方と再利用物を納品する | 継続制作の実例 |

### Disqualifiers

- 事業目的、届けたい相手、採用基準を一切決めたくない
- 品質より迷惑投稿の量だけを求める
- 公開判断と事実確認を完全に放棄したい
- 他者の人格、声、著作物を無断で模倣したい

### Persona-specific form questions

Ask no more than two before contact details.

- `business_use`: 集客 / サービス説明 / 顧客教育 / 採用 / 信頼形成 / 運営者本人の発信
- `business_output_goal`: 画像セット / 動画 / まだ決めていない

Optional after lead submission:

- 既存素材
- 希望する制作頻度
- 現在の外注・制作方法
- 公開先

## 3. Shared persona boundary

| 判断 | 副業に取り組む個人 | 小規模ビジネス運営者 |
|------|------------------|------------------------|
| 最初に得たい結果 | 最初の動画で反応を試す | 事業価値を伝える制作能力を持つ |
| 最初の不安 | 時間と費用を無駄にする | 公開品質と導入負担が事業を傷つける |
| 重視する実例 | 世界観の基準、採用画像群、完成動画、時間、費用 | ブランドに合う画像群、一貫性、採用判断、再利用 |
| 言葉 | 最初の一本、試す、改善する | 事業、自社、蓄積、再利用、公開品質 |
| 行動ボタン | 自分の世界観で動画を作る | ビジネスの画像・動画制作を設計する |
| 最上部の実例 | 知識・経験と世界観が画像群と動画になる | 事業上の依頼とブランド基準が画像セットまたは動画になる |
| 問い合わせ後の成功 | 最初の動画を採用する | 最初の制作物と再利用できる基準を採用する |

同じ広告や顧客層別ページの見出しで `副業もビジネスも` と混ぜない。流入後に顧客層を勝手に変更せず、訪問者が明示的に選び直せるようにする。

## 4. Public-site routing

Common home question:

`作った先に、何を進めたいですか？`

Options:

- `副業の可能性を試したい`
- `ビジネスの価値を伝えたい`

`あなたはどのタイプですか？` とは聞かず、進めたい目的を聞く。顧客層を選んだ後に、`画像をまとめて作る` / `一本の動画を作る` / `まだ決めていない` から制作形式を選べるようにする。

## 5. Proof production backlog

Before paid acquisition, produce at minimum:

### Side-business proof

- 実在する知識・経験と届けたい相手
- 顧客が採用した世界観の基準
- 同じ基準に合う採用画像群
- その画像から作った完成動画
- 時間、費用、修正、採用判断の記録
- 二本目で世界観の基準と画像設定を再利用した実例

### 小規模ビジネス向けの実例

- 実在する事業上の依頼内容
- 採用された画像セットまたは完成動画
- 見た目の一貫性と運営者の採用判断
- 二回目の制作で再利用した素材と基準

神話・民話の実験は `/examples` に残せるが、どちらの顧客層の実例の代わりにもならない。

## 6. Research plan

This document is a decision hypothesis until validated.

For each persona, interview at least five people who match the behavioral condition. Ask about the last real attempt, not general opinions.

Questions:

1. 最後に動画を作ろうとしたのはいつか
2. 何を作ろうとして、どこで止まったか
3. そのとき使った時間、tool、外注、費用は何か
4. 完成しなかったことで何を失ったか
5. 何が見えれば新しい制作方法を信用できるか
6. 最初の1本のあと、何があれば次も作るか
7. self-service / guided / done-for-you のどれを選ぶか、なぜか
8. どのような見た目なら自分の世界観に合うと判断できるか

Update persona assumptions only from repeated patterns. Keep individual anecdotes in research notes, not in this canonical contract.
