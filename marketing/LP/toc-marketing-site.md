# ToC 公開サイト / 紹介ページの文章・画面契約

更新日: 2026-08-29

顧客層、伝える内容、不安、必要な実例の詳細は `marketing/LP/personas.md` を正本とする。このファイルは公開する文章と画面構成を定める。

## 0. 立ち位置

- 存在目的: `人の心を動かし、人生を豊かにする。`
- 顧客に最初に伝える言葉: `あなたの想いを、映像に。`
- 制作範囲: `一枚の画像から、一本の動画まで。`
- ToCの違い: `あなたの世界観に合う画像と動画を。`
- 分類: 副業に取り組む個人と小規模ビジネス運営者のための AI ビジュアル制作システム
- 機能面の約束: `画像も動画も、もっと速く、もっと簡単に。`
- 感情面の約束: `作りたいと思った瞬間を、完成まで止めない。`
- 提供: 画像・動画制作システム一式を顧客環境へ納品する
- 料金: 最初の商品は先着30名限定の導入協力価格29,800円（税込）。31名目以降は59,800円（税込）。その他の商品は個別見積り。納品後の ToC 月額料金は 0 円。外部 AI / cloud サービス料金は別途
- 最初の販売導線: `副業に取り組む個人 × 動画制作`
- 最初に深く届ける顧客像: `自分の知識や経験を、自分の世界観に合う画像で動画にしたい副業個人`
- 中心となる強み: `あなたの世界観に合う画像と動画を。`
- 次の販売市場: 小規模ビジネス運営者

`圧倒的`、時間短縮率、費用削減率は、比較可能な実測が揃った場合だけ公開する。

```text
31名目以降は59,800円（税込）
納品後の ToC 月額料金は 0円

```

### 0秒・3秒・10秒の情報順序

| 理解の目安 | 必ず見えるもの | 訪問者が理解すること |
|------------|----------------|----------------------|
| 0秒 | 見出し | 自分の想いを映像にできる |
| 3秒 | `一枚の画像から、一本の動画まで。` と実在する完成物 | 画像も動画も作れる |
| 10秒 | 世界観の基準、実在する依頼内容と完成物、制作の流れ、行動ボタン | 自分らしい見た目で何を作れ、次に何をすればよいか |

秒数は表示を遅らせる指定ではなく、情報の優先順位である。JavaScript やアニメーションがなくても意味が伝わるようにする。

### 最上部の実例

同じ事例の実在する依頼内容と、採用済みの完成物を一つの視界に置く。

```text
依頼 / 知識・経験・届けたい相手
  +
世界観 / 色・空気感・光・質感・構図・避けたい表現
  ->
画像 / 同じ基準に合う採用画像群
  ->
完成 / その画像で作った採用済み動画
```

最初の販売対象に合わせ、主実例は `副業として知識や経験を伝えたい個人が、自分の世界観に合う画像を使って作った完成動画` とする。画像群は別商品として競わせず、完成動画に本人らしさを与えた根拠として同じ実例内で見せる。

見出しや句点へ操作や別の意味を持たせない。工程カード、AIらしい光彩、架空動画、stock footage を実在する変化の代用にしない。

実例に必要な情報:

- 元の依頼内容と公開可能な抜粋
- 顧客層と、届けたい相手
- 顧客が採用した世界観の基準
- 同じ基準に合う採用画像群と、不採用理由
- 完成動画と静止画
- 制作者の採用判断
- 人間が決めたこと / ToC が進めた工程
- 公開利用の許可
- 計測できた所要時間、人間の作業時間、外部サービス料金、修正回数

現在の確認状況:

| 候補 | 使用場所 | 理由 |
|------|----------|------|
| 浦島太郎の完成動画 | 実例集だけ | 完成実例だが、神話を商品分類に見せないため |
| シンデレラの制作物 | 未使用 | 公開できる完成動画を未確認 |
| 世界観に合う副業向け実在動画 | 最上部候補・不足 | 知識・経験、世界観の基準、採用画像群、完成動画が対応した実例が必要 |

状態は `blocked_missing_worldview_video_proof` とする。適切な実例が承認されるまで、架空の完成物を置いて公開しない。

### 制作の流れ

見出し:

`作るための作業を減らし、作る理由に集中する。`

```text
これまで
企画 -> 個別サービス -> 指示の作り直し -> 素材管理 -> 編集 -> 修正

ToC
目的と一行の案 -> つながった制作工程 -> 人間の確認 -> 完成 -> 次へ再利用
```

ToC は人間を不要にしない。何を伝えるか、どれを採用するか、どこまで公開するかは人間が決める。

## 2. 副業向けページ

場所: `/for-side-business`

このページが最初の販売・広告の主な行き先である。`自分の知識や経験を、自分の世界観に合う画像で動画にしたい副業個人` 一人分の状況へ合わせる。制作形式は動画を初期選択する。

見出し:

```text
あなたの世界観に合う
画像と動画を。
```

補足:

```text
色、空気感、光、質感、構図まで。
あなたらしい画像を作り、一本の動画まで仕上げます。
```

主な行動: `自分の世界観で動画を作る`

行動後は、動画にしたい内容と、伝えたい世界観を入力する。

価格表示:

```text
先着30名限定｜導入協力価格29,800円（税込）
31名目以降は59,800円（税込）
制作システムの導入と最初の一本に対する一回の導入費です。
納品後の ToC 月額料金は0円。外部 AI・クラウドサービス料金は別途かかります。
```

画面の順序:

1. 知識や経験はあるが、自分の世界観に合う画像を作れず、制作負担で止まっている状況
2. 世界観の基準、採用画像群、完成動画という実在する変化
3. 色、空気感、光、質感、構図、避けたい表現を決める方法
4. 顧客が決めること / ToC が支援する工程 / 5回の確認段階
5. 納品する世界観の基準、採用画像、完成動画、生成設定
6. 収益保証はしないこと、権利確認、人間の採用判断、外部料金
7. 先着30名の導入協力価格29,800円、31名目以降59,800円、ToC 月額0円、追加支援の境界
8. 知識・経験と世界観から始めるサイト内フォーム

主な不安への答え:

- `編集経験がない`: 操作習得ではなく、届けたい相手とテーマから始める
- `自分らしい画像になるか`: 最初に見た目の基準と代表画像を確認し、採用後に各場面へ展開する
- `何を作ればよいか分からない`: 自分の知識・経験、届けたい相手、伝えたい変化からテーマを整理する
- `本当に収益になるか`: 収益は保証せず、最初の一本を公開して反応を確かめる
- `AI動画は似たものになる`: 色、空気感、光、質感、構図、避けたい表現を生成より上位に置く
- `続けられるか`: 最初の制作で使った素材と判断を次へ引き継ぐ

## 3. 小規模ビジネス向けページ

場所: `/for-small-business`

次の販売市場として設計と自然流入の受け皿を持つ。最初の有料集客の主導線にはしない。

見出し:

```text
伝えたい事業の価値を、
使い続けられる画像・動画へ。
```

補足:

```text
商品、サービス、知識を、自社の表現基準を保ったまま、
ブランドの世界観に合う、改善・再利用できる画像・動画へ変えます。
```

主な行動: `ビジネスの画像・動画制作を設計する`

画面の順序:

1. 伝える内容はあるが、専任の制作担当がいない状況
2. 実在する事業上の依頼と、採用済み画像セットまたは動画
3. 画像一括生成と動画制作の利用例を分けて提示
4. 目的、届けたい相手、色、空気感、光、質感、構図、避けたい表現、採用基準
5. 顧客と ToC の担当範囲、確認、修正、公開判断
6. 単発外注と、自社へ素材・判断が蓄積する仕組みの違い
7. 制作システム納品、導入費、ToC 月額 0 円、外部料金
8. 一行入力とサイト内フォーム

個人ブランドは、運営者本人の専門知識や信用を伝える利用例として、このページ内に置く。

主な不安への答え:

- `自社らしさが消えそう`: ブランドの世界観を確認可能な見た目の基準へ変え、生成より上位に置く
- `公開品質が不安`: 人間の採用・修正・公開判断と実例を見せる
- `導入が重そう`: 初回に必要な顧客作業と納品後の運用を明示する
- `外注で十分`: 二回目に再利用できた素材と判断を示す
- `費用が読めない`: 導入費、ToC 月額、外部料金、追加支援を分ける

## 4. 実例集

実例は顧客層と制作形式を別々に絞り込めるようにする。

顧客層:

- 副業に取り組む個人
- 小規模ビジネス運営者
- 制作能力の実験

制作形式:

- 画像一括生成
- 動画制作

各実例に表示する内容:

- 最初の依頼内容
- 目的と届けたい相手
- ブランドや世界観を表す見た目の基準
- 同じ基準から作った採用画像群
- 完成物
- ToC が進めた工程
- 人間が決めたこと
- 計測できた時間、費用、修正
- 採用判断
- 次回へ再利用したもの

神話・民話は `制作能力の実験` に分類し、主な商品用途に見せない。

## 6. 禁止する表現

- 誰でも必ず稼げる
- 放置で収益
- 完全自動で完璧
- 人間不要
- 世界初
- 根拠のない時間短縮率や費用削減率
- 画像数だけを根拠にした大量生成
- 神話・民話を ToC 全体の商品目的として扱う表現
