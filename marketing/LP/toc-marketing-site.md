# ToC marketing site / LP content contract

更新日: 2026-07-19

Persona、message、objection、proof の詳細契約は `marketing/LP/personas.md` を正本とする。このファイルでは page section と公開 copy の境界だけを定義する。

## 0. Positioning

- category: 個人向け AI 動画制作システム
- functional promise: `動画制作を、圧倒的に速く、簡単に。`
- emotional promise: `作りたいと思った瞬間を、完成まで止めない。`
- transformation: `速いから試せる。簡単だから続けられる。続けられるから副業やブランドへ育てられる。`
- proof policy: `圧倒的` は比較可能な実測がある場合だけ公開する

### Three values

#### 速いから試せる

制作工程を毎回ゼロから組み立てない。アイデアを反応の見える完成物へ進める。

#### 簡単だから続けられる

複数サービスを行き来し、同じ指示を作り直す負担を減らす。

#### 続けられるから育てられる

単発の動画ではなく、改善可能な制作フローを持つ。副業の検証もブランドの蓄積も、次の1本から始まる。

### Why ToC

Heading:

`作るための作業を減らし、作る理由に集中する。`

Comparison:

```text
従来
企画 -> 個別ツール -> prompt 作成 -> 素材管理 -> 編集 -> 修正

ToC
テーマ -> 統合された制作フロー -> 人間の判断 -> 完成
```

Do not claim that humans are unnecessary. Explain that ToC reduces fragmented operation while humans retain purpose, quality, and publishing decisions.

### Proof library

Every example shows:

- initial theme / brief
- completed video
- format and duration
- ToC-owned stages
- human-owned decisions
- elapsed production time
- human working time
- revision count
- reusable assets

Example categories:

- 解説動画
- 個人ブランド動画
- 商品・サービス紹介
- Shorts
- long-form YouTube
- story / mythology experiments

### Human judgment

Heading:

`速くても、任せきりにはしない。`

Copy:

```text
ToC は制作工程を進めます。
何を伝えるか、どこまで公開するか、品質を受け入れるかは人間が決めます。
```

### Final CTA

Heading: `あなたなら、何を動画にしますか？`

Primary CTA: `テーマを一行で入れる`

## 2. Side-business LP

Path: `/for-side-business`

### Hero

Headline:

```text
動画副業を、
「作れない」で終わらせない。
```

Subcopy:

```text
最初の1本を作るために、動画制作のプロになる必要はありません。
ToC が企画から完成までの制作工程を一つにつなぎます。
```

Primary CTA: `副業の最初の1本を作る`

### Emotional sequence

```text
時間がない / 編集できない / ツールが多い
  -> 自分にも完成させられる
  -> 最初の1本で反応を試せる
  -> 改善しながら続けられる
  -> 収益の種を育てられる
```

### Required sections

1. 本業後に編集ソフトと格闘しなくてよい未来
2. 一行のテーマから完成までの demo
3. 副業向け formats and examples
4. time / effort comparison with evidence
5. what ToC does / what the user decides
6. realistic limits: no revenue guarantee, quality needs judgment, provider costs may apply
7. CTA and native form

### Objection handling

- `編集経験がない`: 操作習得より目的とテーマの入力から始める
- `何を作ればよいか分からない`: niche / audience / outcome の brief を一緒に定める
- `本当に収益になるか`: 収益を保証せず、低い制作負担で検証回数を増やす価値を伝える
- `AI動画は似たものになる`: 目的、視聴者、tone、series rules を固定して差を作る

## 3. Personal-brand LP

Path: `/for-personal-brand`

### Hero

Headline:

```text
頭の中にあるものを、
発信できるブランドへ。
```

Subcopy:

```text
あなたの知識、経験、思想、世界観を、
一貫して続けられる動画制作フローに変えます。
```

Primary CTA: `自分のブランド動画を設計する`

### Emotional sequence

```text
伝えたいのに形にできない
  -> 自分らしさを保って動画にできる
  -> 発信を止めずに続けられる
  -> 動画が資産として蓄積する
  -> この分野ならこの人、という認知になる
```

### Required sections

1. content knowledge exists but production capacity is missing
2. brand brief: audience / belief / tone / visual rules / prohibited expressions
3. one idea into a repeatable series
4. personal-brand examples
5. consistency and human approval
6. comparison with one-off outsourcing and fragmented self-production
7. CTA and native form

### Objection handling

- `AIで個性が消えそう`: AIの既定表現ではなく、brand brief を正本にする
- `品質が不安`: human approval と example evidence を見せる
- `自分で話した方が早い`:本人出演、voice、faceless、narrative など複数 format を選べる
- `継続できるか`: single output ではなく reusable series structure を設計する

## 4. Copy guardrails

Use:

- 作れる
- 速く試せる
- 続けられる
- 自分のテーマ
- 最初の1本
- 発信を資産にする
- 人間が判断する

Avoid:

- 誰でも必ず稼げる
- 放置で収益
- 完全自動で完璧
- 人間不要
- 世界初
- 根拠のない時間短縮率
- 神話・民話を ToC 全体の目的として扱う表現
