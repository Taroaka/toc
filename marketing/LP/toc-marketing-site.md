# ToC 公開サイト / 紹介ページの文章・画面契約

更新日: 2026-08-09

顧客層、伝える内容、不安、必要な実例の詳細は `marketing/LP/personas.md` を正本とする。このファイルは公開する文章と画面構成を定める。

## 0. 立ち位置

- 存在目的: `人の心を動かし、人生を豊かにする。`
- 顧客に最初に伝える言葉: `あなたの想いを、映像に。`
- 制作範囲: `一枚の画像から、一本の動画まで。`
- 分類: 副業に取り組む個人と小規模ビジネス運営者のための AI ビジュアル制作システム
- 機能面の約束: `画像も動画も、もっと速く、もっと簡単に。`
- 感情面の約束: `作りたいと思った瞬間を、完成まで止めない。`
- 提供: 画像・動画制作システム一式を顧客環境へ納品する
- 料金: 導入費用は個別見積り。納品後の ToC 月額料金は 0 円。外部 AI / cloud サービス料金は別途
- 最初の販売導線: `副業に取り組む個人 × 動画制作`
- 次の販売市場: 小規模ビジネス運営者

`圧倒的`、時間短縮率、費用削減率は、比較可能な実測が揃った場合だけ公開する。

## 1. 共通サイト

### 最上部

見出し:

```text
あなたの想いを、
映像に。
```

制作範囲:

```text
一枚の画像から、一本の動画まで。
```

実現方法:

```text
企画、構成、画像、動画、音声、編集を、
ひとつの制作の流れへ。
```

補足:

```text
画像も動画も、もっと速く、もっと簡単に。
ToC は、作り続けるための制作システム一式をあなたの環境へ納品します。
```

主な行動:

```text
作りたい画像・動画を一行で入力する
```

これは上流の共通導線を画面の言葉へ翻訳したスレッド2の推奨案であり、共通ボタンの最終承認は `workstream-handoffs.md` の引き継ぎ001でスレッド1へ依頼する。

入力後にすぐ自動生成されるようには見せない。補足として `入力内容を確認し、導入方法をご案内します` を近接表示する。

副業向けの主導線: `副業の最初のコンテンツを作る`

第二の行動: `制作事例を見る`

料金の注記:

```text
導入費用は個別見積り
納品後の ToC 月額料金は 0円
※外部 AI・クラウドサービス料金は別途、使用量に応じて発生
```

### 0秒・3秒・10秒の情報順序

| 理解の目安 | 必ず見えるもの | 訪問者が理解すること |
|------------|----------------|----------------------|
| 0秒 | 見出し | 自分の想いを映像にできる |
| 3秒 | `一枚の画像から、一本の動画まで。` と実在する完成物 | 画像も動画も作れる |
| 10秒 | 実在する依頼内容との対応、制作の流れ、行動ボタン、料金注記 | 何をする仕組みで、次に何をすればよいか |

秒数は表示を遅らせる指定ではなく、情報の優先順位である。JavaScript やアニメーションがなくても意味が伝わるようにする。

### 最上部の実例

同じ事例の実在する依頼内容と、採用済みの完成物を一つの視界に置く。

```text
依頼 / 実際の一行
  ->
完成 / 同じ依頼から作った採用済み動画
```

最初の販売対象に合わせ、主実例は `副業として発信を始めたい個人の、具体的なテーマから作った完成動画` とする。画像一括生成は、同じ最上部で別商品として競わせず、制作範囲の短い実例または次の画面で見せる。

見出しや句点へ操作や別の意味を持たせない。工程カード、AIらしい光彩、架空動画、stock footage を実在する変化の代用にしない。

実例に必要な情報:

- 元の依頼内容と公開可能な抜粋
- 顧客層と、届けたい相手
- 完成動画と静止画
- 制作者の採用判断
- 人間が決めたこと / ToC が進めた工程
- 公開利用の許可
- 計測できた所要時間、人間の作業時間、外部サービス料金、修正回数

現在の確認状況:

| 候補 | 使用場所 | 理由 |
|------|----------|------|
| 浦島太郎の完成動画 | 実例集だけ | 完成実例だが、神話を商品分類に見せないため |
| シンデレラの制作物 | 未使用 | 公開できる完成動画を未確認 |
| 副業向けの実在動画 | 最上部候補・不足 | 最初の販売対象に合う依頼内容と採用済み完成物が必要 |

状態は `blocked_missing_side_business_video_proof` とする。適切な実例が承認されるまで、架空の完成物を置いて公開しない。

### 顧客層の分岐

見出し:

主導線:

```text
副業の可能性を試したい

```

次市場の導線:

```text
ビジネスの価値を伝えたい

[小規模ビジネス向けを見る]
```

共通サイトでは両方を案内できるが、最初の販売期間は副業向けを主導線として先に、強く見せる。広告からは顧客層別ページへ直接送る。

### 画像一括生成の実例

見出し:

`必要な画像を、まとめて。`

一つの依頼内容に対して、用途、見た目の基準、必要点数、別案、採用結果が分かる実例を置く。生成枚数だけを価値にせず、次を示す。

- 依頼した点数
- 生成した候補点数
- 採用点数と採用理由
- 不採用点数と別案
- 一貫性の基準
- 所要時間、人間の作業時間、外部サービス料金
- 次の動画や画像制作へ再利用した素材

### 制作の流れ

見出し:

`作るための作業を減らし、作る理由に集中する。`

```text
これまで
企画 -> 個別サービス -> 指示の作り直し -> 素材管理 -> 編集 -> 修正

ToC
目的と一行の案 -> つながった制作工程 -> 人間の確認 -> 完成 -> 次へ再利用
```

ToC は人間を不要にしない。何を伝えるか、どれを採用するか、どこまで公開するかは人間が決める。

### 提供形態

見出し:

`借り続ける制作サービスではなく、作り続けるためのシステムを手元へ。`

- 制作システム一式を顧客環境へ納品
- 導入費用は個別見積り
- 納品後の ToC 月額料金は 0 円
- 外部 AI / cloud サービス料金は別途、使用量に応じて発生
- 保守、更新、運用代行は必要な場合に別契約

### 最後の行動

見出し: `あなたなら、何を作りますか？`

主な行動: `作りたい画像・動画を一行で入力する`

## 2. 副業向けページ

場所: `/for-side-business`

このページが最初の販売・広告の主な行き先である。制作形式は動画を初期選択する。

見出し:

```text
動画副業を、
「作れない」で終わらせない。
```

補足:

```text
最初の一本を作るために、動画制作のプロになる必要はありません。
ToC が企画、構成、画像、映像、音声、編集を一つの制作の流れへつなぎます。
```

主な行動: `副業の最初のコンテンツを作る`

行動後は動画テーマを一行で入力する。

画面の順序:

1. 本業後に制作サービスと格闘しなくてよい未来
2. 実在する一行のテーマと採用済み完成動画
3. 人間が決めること / ToC が進める工程
4. 実測できた時間、作業、費用、修正
5. 収益保証はしないこと、品質判断と外部料金が必要なこと
6. 制作システム納品、導入費、ToC 月額 0 円、外部料金
7. 一行入力とサイト内フォーム

主な不安への答え:

- `編集経験がない`: 操作習得ではなく、届けたい相手とテーマから始める
- `何を作ればよいか分からない`: 対象者、困りごと、伝えたい変化を整理する
- `本当に収益になるか`: 収益は保証せず、最初の一本を公開して反応を確かめる
- `AI動画は似たものになる`: 目的、視聴者、表現基準、採用判断を制作の上位に置く
- `続けられるか`: 最初の制作で使った素材と判断を次へ引き継ぐ

## 3. 小規模ビジネス向けページ

場所: `/for-small-business`

次の販売市場として設計と自然流入の受け皿を持つ。最初の有料集客の主導線にはしない。

見出し:

```text
伝えたい事業の価値を、
使い続けられる画像・動画へ。
```

補足:

```text
商品、サービス、知識を、自社の表現基準を保ったまま、
改善・再利用できる画像・動画制作へ変えます。
```

主な行動: `ビジネスの画像・動画制作を設計する`

画面の順序:

1. 伝える内容はあるが、専任の制作担当がいない状況
2. 実在する事業上の依頼と、採用済み画像セットまたは動画
3. 画像一括生成と動画制作の利用例を分けて提示
4. 目的、届けたい相手、見た目、禁止表現、採用基準
5. 顧客と ToC の担当範囲、確認、修正、公開判断
6. 単発外注と、自社へ素材・判断が蓄積する仕組みの違い
7. 制作システム納品、導入費、ToC 月額 0 円、外部料金
8. 一行入力とサイト内フォーム

個人ブランドは、運営者本人の専門知識や信用を伝える利用例として、このページ内に置く。

主な不安への答え:

- `自社らしさが消えそう`: 事業目的と表現基準を生成より上位に置く
- `公開品質が不安`: 人間の採用・修正・公開判断と実例を見せる
- `導入が重そう`: 初回に必要な顧客作業と納品後の運用を明示する
- `外注で十分`: 二回目に再利用できた素材と判断を示す
- `費用が読めない`: 導入費、ToC 月額、外部料金、追加支援を分ける

## 4. 実例集

実例は顧客層と制作形式を別々に絞り込めるようにする。

顧客層:

- 副業に取り組む個人
- 小規模ビジネス運営者
- 制作能力の実験

制作形式:

- 画像一括生成
- 動画制作

各実例に表示する内容:

- 最初の依頼内容
- 目的と届けたい相手
- 完成物
- ToC が進めた工程
- 人間が決めたこと
- 計測できた時間、費用、修正
- 採用判断
- 次回へ再利用したもの

神話・民話は `制作能力の実験` に分類し、主な商品用途に見せない。

## 6. 禁止する表現

- 誰でも必ず稼げる
- 放置で収益
- 完全自動で完璧
- 人間不要
- 世界初
- 根拠のない時間短縮率や費用削減率
- 画像数だけを根拠にした大量生成
- 神話・民話を ToC 全体の商品目的として扱う表現
