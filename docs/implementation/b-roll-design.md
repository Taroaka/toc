# 人物を出さないBロールの設計

## 適用と目的

ToCで空気感・余韻・scene間の接続を担うBロールは `cut_role: sub` とする。
`main` は出来事、選択、必須情報を成立させる。`sub` はそれを受け止める時間、場所の感触、
次sceneへの準備を作る。人物が映らないだけでBロールになるわけではなく、重要な証拠の初提示や
事件を進める物の動きは、物だけの画面でも `main` として設計する。

一般のBロールは人物を含み得る。「人物なし」は今回のToCの制作方針であり、映画用語一般の定義ではない。
既存runを自動で再分類せず、新規作成・明示的に依頼された再設計に適用する。

## 人物なしの範囲

- 顔、身体、手足、後ろ姿、群衆、シルエット、人の影、鏡や水面の人物反射を画面に入れない。
- 人物像を主題にした肖像画・人形・彫像で代替しない。人物参照画像もBロールの必須参照にしない。
- 主役は既存の場所、建築、物、素材、光、水、煙、風など。人物退出後の状態は使えるが、
  退出する人物そのものはこのcutに映さない。
- 手が物を置く、画面外の誰かが扉を開ける等、新しい人物行動を暗示する変化は追加しない。
  既に成立した状態の保持や、因果を変えない環境の微動を使う。
- 鳥などの生物を無条件に追加しない。採用する場合は原資料・場所との整合を確認し、
  新しい登場主体や事件を作らない。

## scene境界での選び方

p420で、前sceneの終わりと次sceneの始まりを一組で読み、接続を決める。
まず「何を見せるか」より「観客にどんな間・場所の感触を渡すか」を一文にする。

1. 必須の出来事・台詞・選択・理解に必要な情報をmainで完了させる。
2. 余韻、場所の導入、時間の移行、視覚的な接続のうち、今回必要な役割を選ぶ。
3. 下の技法から選び、具体的な被写体、構図、動き、音、終えるタイミングを決める。
4. 前scene末尾か次scene冒頭のどちらに所有させるかを決め、二重計上しない。
   次の場所を見せるcutは、通常はその場所を持つ次sceneに置く。
5. 1cutを出発点に検討するが、固定本数にはしない。直接接続が必要なら0cut、
   2cutなら「細部の余韻→次の場所の全景」など異なる役割を説明する。
   同じ空気感の繰り返しや目標尺の穴埋めでは増やさない。

最終sceneは次sceneの導入ではなく、終わりの余韻を判断する。scene途中でも、
進行を止める意味があれば環境へのcutawayを選べる。全scene末尾1〜2cut固定は採用しない。

## 表現技法カタログ

以下は既存の映画技法を、人物なしの生成映像へ適用した制作上の選択肢。
技法名だけをpromptに渡さず、右欄を具体化する。例は構造の説明であり、作品に自動挿入する素材ではない。

| 技法 | 担う役割・選ぶ条件 | 人物なしでの表現と設計事項 |
| --- | --- | --- |
| 無人のエスタブリッシング [1] | 場所や時間帯が変わる境界 | 既存の建物外観、通路、部屋の全景。光源・時刻・向きを揃え、次のmainで位置関係を理解できる構図にする。固定か緩い移動を一つ選ぶ。 |
| ピローショット [2] | 出来事の後に間を置き、日常の空間を感じさせる | 無人の室内、窓辺、生活の物。安定した構図で保持する。新しい事件や説明を足さず、物語から一時的に距離を取る。 |
| 環境へのカットアウェイ [3] | 主動作から短く離れ、場所の空気や時間感覚を補う | 雨の窓、風に動く布、水面など、既存環境の一部へ視線を移す。元の場面に戻る場合は同じ時間・状態を維持する。sceneを移る場合は接続先を明記する。 |
| 物・素材のインサート [4] | 既に示した物の質感や余韻を感じさせる | 無人の机上の物、布目、煤、石、ガラス等を寄りで見せる。浅い被写界深度や小さなpush-inは必要な時だけ。初めて読ませる手紙や新しい手掛かりはmainにする。 |
| 空間に残った痕跡 | 直前の出来事の余韻を、人物の不在で受け止める | 既に成立した配置や痕跡を保持する。上記ピローショット／インサートのToC向け応用で、独立した標準用語ではない。新たな足跡、破損、持ち物を捏造しない。 |
| 形・構図・光のマッチカット [5] | 異なる場所の間に視覚的な連続性を作る | 前後に実在する形・色・画面位置などを一つ合わせる。二つのcutを対で設計し、つなぐフレームを指定する。同じ形だから同じ物だと誤解させない。 |
| 環境の微動を保持する | 静止に近い画面の中で時間と空気を感じさせる | 既存の光、炎、水、煙などから主な微動を一つ選ぶ。これは環境cutaway等の生成向け応用。新しい天候や魔法、急な消灯などの事件に変えない。 |

人物の反応ショットや手元のinsertは、今回の人物なしsubには含めない。
時間経過を示す明暗変化・タイムラプスは、storyが認める時間移行に限る。
「空気感」のために朝を夜へ変えたり、雨や季節を新設したりしない。

## 音とナレーション

Bロールは「音声なし」と同義ではない。ナレーションを休ませ、環境音や音楽でつなぐ案を
まず検討する。ナレーションを重ねる場合も第三者視点を守り、新しい必須情報をこのcutだけで説明しない。
人物なしは画面の制約であり、ナレーター音声まで禁止するものではない。

- 環境音を続ける: 前後で同じ場所なら連続した空気を保つ。場所が変わる場合は音源の整合を確認する。
- Jカット [6]: 次sceneの音を映像より先に入れる。未開示の出来事や人物を音で先に明かさない。
- Lカット [6]: 前sceneの音を次の映像へ残し、感情や空間の余韻を渡す。

J/Lカットは編集技法であり、画像・動画promptだけでは成立しない。音のsource、前後のcut selector、
開始・終了位置をhandoffへ記録し、render側が対応できることを確認してから採用する。
本設計書への掲載は自動ミックス実装を意味しない。非対応なら通常のcut内環境音と直接接続を使う。
TTSの `silent` はナレーションの無音指定であり、環境音や音楽のミュート指示にはしない。

## 既存cut設計への記入

cut contractの新しい必須schemaは追加しない。scriptのblueprintからmanifestの `cut_contract` へ、
既存項目を使って次を一方向に引き継ぐ。

| 項目 | 記入する内容 |
| --- | --- |
| `cut_role` | `sub`。接続用途でもこのBロールを `main` や `transition` に置き換えない。 |
| `cut_function` | 余韻／場所導入などの具体的役割。open authoring keyを使い、技法名だけで済ませない。 |
| `viewer_contract` | 伝える空気感、具体的な可視要素、人物除外。知識が増えない場合もその旨を記す。 |
| `cinematic_contract` | 人物でなく場所・物をprimary subjectにし、構図・光・撮影距離を指定する。 |
| `source_event_contract` | このcutが保持する既存eventの状態・source IDs・開示境界。架空のBロール専用eventは作らない。 |
| `first_frame_contract` | 誰もいない開始状態、既存の物の配置、反射を含む人物除外。動きの結果を先に描かない。 |
| `motion_contract` | カメラまたは環境の小さな動きと終了状態。人物の侵入や新しい事件を追加しない。 |
| `asset_dependency` | 必須character IDsは空。必要な既存location/object IDsだけを選び、人物を含む参照画像を強制しない。 |
| `cut_handoff` | 前後の実selectorと、光・形・音など何を受け渡すか。終端の場合はterminal扱い。 |
| `narration_contract` / `downstream_handoff` | ナレーションの有無、音の意図、採用技法、編集条件、scene境界の所有とcut数の理由。 |

scriptでは `cut_blueprint.must_avoid`、manifestでは `viewer_contract.must_avoid` と
`first_frame_contract.must_avoid` に人物・身体部分・影・反射の除外を具体的に書く。
下流画像・動画promptでも同じ条件を維持する。既存validatorが人物の存在を必須にしている場合は、
ダミーの人物やsource IDを補わず、その不整合を実装課題として報告する。

## authoring時の確認

- mainだけで必須の出来事が理解でき、subに新しい事件・唯一の証拠を追い出していない。
- 画面・参照素材・動作に人物を混入させず、既存の場所・物・時間・開示順を保っている。
- 空気感を伝える具体的な被写体があり、抽象語だけのpromptになっていない。
- 前scene末尾と次scene冒頭で同じ役割を重複させず、前後の接続と終える理由が明確。
- 尺は微動や余韻を読む時間とproviderの対応範囲から決める。固定秒数やカット数の穴埋めにしない。
- 普通のsource/selector/asset/first-frame/motion検証を維持する。新たな批評・スコア工程は設けない。

これはauthoring指示であり、人物不在を検出する自動画像検証器を追加したものではない。

## 新規作成の実装経路

新規p300 authorは各sceneに `boundary_b_roll: {reason, cuts}` を返す。
runtimeが `visual_value_metadata.b_roll_policy: boundary_b_roll_v1` を付け、判断の欠落を拒否する。
`cuts` は原則1件、直接接続は理由付き0件、異なる役割がある場合は2件。
各件の必須文字列は `technique / source_event_beat_id / location / subject / first_frame /
motion / end_state / foreground / background / light`。techniqueは
`establishing|pillow|cutaway|insert|aftermath|match|environment_hold`。
sourceはscene最後の既存beat、locationは終了場所の原文名にする。

p420がこれをscene末尾のsubへ確定・投影する。現在の実装は終了場所での保持を対象とし、
次の場所への先行移動や音のJ/L自動編集は行わない。通常のmainをsubへ置換せず、
全cutへscene総尺を再配分する。人物・styleの参照を自動追加せず、既存location参照を保持する。
画像compilerと動画compilerは人物・身体部分・影・反射の除外を出力し、人物ID付きsubは拒否する。
無音は `source: boundary_b_roll_v1` のauthor判断として記録し、人間が確認したという記録は作らない。

policy markerのない既存runは自動変更しない。生成後の実画像・動画で人物が入らないことを
保証する検出器ではなく、authoring・参照選択・provider入力までの構造的な対応である。

## 調査出典

2026-09-19確認。用語と編集原理は以下を参照。人物除外、main/subの責務、生成時の制約はToC独自の設計判断。

1. [Adobe — B-roll](https://www.adobe.com/creativecloud/video/discover/b-roll.html): 補助映像による場所の提示と接続、事前のshot list。
2. [BFI — The enigmatic ‘pillow shots’ of Yasujiro Ozu](https://www.bfi.org.uk/features/enigmatic-pillow-shots-yasujiro-ozu): 物や風景を捉える、物語の合間のショット。
3. [StudioBinder — Cutaway shot](https://www.studiobinder.com/blog/cutaway-shot/): 主動作から視線を外すショットと時間・空間の扱い。
4. [StudioBinder — Insert shot](https://www.studiobinder.com/camera-shots/framing/insert-shot/): 同じscene内の細部の強調、撮影上の選択肢。
5. [Adobe — Match cut](https://www.adobe.com/uk/creativecloud/video/discover/match-cut.html): 二つのショットの視覚的類似による接続。
6. [Adobe — J and L cuts](https://helpx.adobe.com/sg/premiere/desktop/edit-projects/trim-clips/perform-j-cuts-and-l-cuts.html): 映像の切替と音の切替をずらす編集。
