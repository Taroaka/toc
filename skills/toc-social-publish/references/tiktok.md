# TikTok Studio

対象は国際版TikTok。Douyinのセレクタ・制限を転用しない。

1. TikTok公式サイトからStudioまたはUploadへ進み、本人のハンドルを確認する。
2. 現行UIで許可された方法でファイルを添付する。アップロードと処理が終わるまで投稿画面から離れない。戻る操作で破棄確認が出たら、未保存素材を捨てない。
3. caption・タグ・カバーと、公開範囲・コメント等の指定を反映する。必要なAI生成・広告表示を確認する。販売リンクや音源を勝手に追加しない。
4. scheduleなら実画面に予約機能があるか確認し、日付・時刻・タイムゾーンを読み戻す。アカウント種別や予約可能日数はその場で確認する。
5. prepareで保存UIがなければpreparedとして画面を引き継ぐ。投稿前の編集画面を、保存済み下書きと報告しない。
6. 承認済み公開/予約を1回送信する。StudioのContent等、画面に存在する管理一覧で動画・caption・日時を照合する。
7. 審査中/処理中はsubmitted、予約確認はscheduled、公開表示と対象を確認できた場合のみpublished。取得できるURL/IDと証拠を台帳へ記録する。

公式入口：https://www.tiktok.com/tiktokstudio
公式案内：https://support.tiktok.com/en/using-tiktok/creating-videos/creator-tools-on-tiktok

この文書は操作目的を定めるもので、現在の本人アカウントで動作検証済みのクリック列ではない。
