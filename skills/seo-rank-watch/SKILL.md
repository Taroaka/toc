# SEO Rank Watch

1. ToC リポジトリの `marketing/README.md` と `marketing/SEO/rank-watch.md` を読む。後者を運用手順の正本とする。インストール先ではなく ToC リポジトリから解決する。
2. 対象サイトのリポジトリ、公開 URL、GSC プロパティと利用可能な計測手段を確認する。未指定のサイトを推測して変更しない。
3. 正本に従い、測定 → 期限が来た改善のレビュー → 候補1つの選定 → 検索意図調査 → 改善 → 記録・7日観察 → 報告を1回実行する。

1回の改善は必ず1キーワードまで。`observing` は `nextReviewDate` まで再改善せず、`achieved` は監視だけにする。候補がなければ計測・報告だけで終了する。

このスキルの追加や読み込みだけでは、サイト公開や定期実行の開始を意味しない。継続実行の依頼がある場合は利用環境のスケジューラで次回を設定し、7日間を待つために実行中のループを維持しない。1位達成後も監視を続け、順位改善は保証しない。
