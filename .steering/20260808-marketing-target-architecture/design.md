# ToC marketing target architecture design

更新日: 2026-08-08

## Architecture

```text
Purpose
  -> あなたの想いを、映像に。
  -> side_business
       first video / market validation / repeatable creation
  -> small_business_operator
       business communication / reusable capability / continued creation
       -> personal brand as one use case
```

## Shared problem

両 target とも、動画を必要としているが専任制作機能を持たず、分断された tool、学習、外注、継続負荷で止まる。

## Required separation

- side_business は個人の時間、予算、最初の公開、市場反応を中心にする
- small_business_operator は事業目的、公開品質、再利用、導入・保守を中心にする
- 共通 brand line は使えるが、persona-specific Hero、proof、CTA、qualification を同一化しない

## Unknowns remain hypotheses

- small business の従業員数 / 売上境界
- 最初の business use case
- offer package / price / support boundary
- target 別の支払意思
- paid acquisition の優先順位

## Projection boundary

- Workstream 1 は上位 decision と handoff を作る
- Workstream 2 は LP / route / form / event へ投影する
- Workstream 3 は proof / acquisition / analytics へ投影し、evidence を返す
