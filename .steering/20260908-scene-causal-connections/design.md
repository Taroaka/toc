# Design

Use a shared authoring instruction, with an authored causal_connection_from_previous string in each scene plan (opening: null). Scene Authors project this reason into existing first-beat trigger, start_state, and incoming handoff fields. Preserve this through repair. An unsupported causal connection must be identified as a source gap, never invented as fact. This is an authoring requirement, not a deterministic semantic verdict or new review stage. Existing schema compatibility and parallel execution remain intact.
