# マーケティング文書を分かりやすい日本語へ統一する設計

更新日: 2026-08-09

## 書き方の順序

説明は次の順で行う。

```text
顧客が理解できる日本語
  -> 必要な場合だけ概念の意味を一文で説明
  -> 正確さのために必要な識別名や略語
```

## 言い換えの基準

- 直訳ではなく、その言葉がこの文書内で果たす役割を日本語で書く
- 一つの用語に無理に固定せず、文脈に応じて `実例`、`根拠`、`証拠` などを使い分ける
- 内部用の制作形式は、`画像一括生成` と `動画制作` の2つとして説明する
- スレッド間の連携は、`引き継ぎ` と書き、渡す内容を具体的に列挙する
- 顧客を選別する概念は、`商談対象とする条件` と `対象外とする条件` に分けて説明する

## 反映範囲

- スレッド1の3つの正本を日本語化する
- 今後のマーケティング作業にも適用されるよう、作業用の案内へ規則を追加する
- スレッド2・3には開始指示を通して方針を渡し、担当ファイルは変更しない
