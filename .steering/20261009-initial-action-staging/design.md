# Design

Extend cinematic execution with an optional `staging` block containing static
`first_frame_requirements`, `action_sequence`, `end_behavior` (hold/continue/exit and description),
and `continuity_rules`. The author writes these from source; runtime does not invent them.
Project static requirements through the existing still pose field; video fragments preserve the
ordered sequence, explicit end behavior and invariants. Include generic feasibility, individual
reaction and source-authorized transformation guidance in the initial p420 prompt.
Version the author policy/cache binding so new authoring cannot silently reuse a prior-policy row.
No new production stage, evaluator, provider or frontend toggle.
