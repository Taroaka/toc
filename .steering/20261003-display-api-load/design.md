# Design
Display-only bounded parsed-manifest cache keyed by canonical file and directory identity, size, mtime and ctime; safe C YAML loader where available and copy-on-read. One manifest snapshot per item list, reused by video candidate provenance checks. Retain provenance checks for actual candidates. Async single-flight display reads with shielded cancellation and cleanup; offload synchronous work with to_thread while retaining existing narration write coordination. Display progress skips generation-grade validation. Frontend renders image metadata first and merges narration later with scope/mutation guards.
