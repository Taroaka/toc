# 最初の顧客像を決める設計

更新日: 2026-08-10

## 顧客の階層

```text
主な顧客層
  副業に取り組む個人
    -> 最初の顧客像
       自分の知識や経験を、顔出しなしの動画にしたい副業個人
```

## この人が置かれている状況

- 人へ伝えられる知識や経験を持っている
- その内容を副業の発信や反応検証に使いたい
- 顔を出したくない、または顔出しを前提にすると始められない
- 構成、素材作り、音声、編集を一人で扱う負担によって止まっている
- 最初の一本にする具体的なテーマがある

## 届ける変化

```text
頭の中に知識や経験がある
  -> 顔を出さずに制作できる
  -> 構成、画像、映像、音声、編集が一本につながる
  -> 公開できる動画になる
  -> 次の制作を始められる
```

## 顧客へ届ける言葉の案

`顔を出さずに、あなたの知識と経験を動画に。`

この言葉は顧客層別ページや広告で検証する案であり、共通の言葉 `あなたの想いを、映像に。` を置き換えない。
