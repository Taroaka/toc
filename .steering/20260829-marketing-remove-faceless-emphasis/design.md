# 顔出しなしの強調を外す設計

更新日: 2026-08-29

## 顧客像

```text
副業に取り組む個人
  -> 自分の知識や経験がある
  -> 自分の世界観に合う画像で表現したい
  -> その画像を使って動画を完成させたい
```

## 言葉の階層

共通の入口:

`あなたの想いを、映像に。`

最初の商品の中心:

`あなたの世界観に合う画像で、知識と経験を動画に。`

商品の違い:

`あなたらしさは、世界観で伝わる。`

## 顔の扱い

人物を映す、映さない、生成した人物やキャラクターを使うなどの選択は、テーマと顧客の希望に応じて決める。販売対象を決める条件や商品の中心価値にはしない。
