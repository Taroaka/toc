# 導入協力価格と3本比較を決める設計

更新日: 2026-08-29

注記: 価格比較の基本表現は、`.steering/20260829-marketing-brand-worldview-value/` により、`3本分の編集外注費で、あなたの世界観に合う画像と動画を。` へ更新された。

## 価格構造

```text
販売設計上の本価格
  59,800円（税込）

導入協力価格
  先着30名 29,800円（税込）

31名目以降
  59,800円（税込）
```

公開時は、`先着30名限定｜導入協力価格29,800円（税込）` と `31名目以降は59,800円（税込）` を近くに表示する。59,800円を販売実績のある通常価格とは呼ばず、31名目以降に適用する価格として説明する。

## 人数の数え方

```text
適合条件を確認
  -> 契約成立
  -> 支払い手続き完了
  -> 先着人数へ加算
```

問い合わせ、相談、見積り依頼だけでは加算しない。残り人数を公開する場合は、アクセス制限された販売記録と一致する数字だけを使う。30名へ達した時点で29,800円の受付を終了する。

## 3本比較

```text
動画編集外注 1本10,000円 × 3本
  = 30,000円

ToC 導入協力価格
  = 29,800円

差額
  = 200円
```

## 表現の階層

一番短い表現:

`3本分の編集外注費で、あなたの世界観に合う画像と動画を。`

説明を加えた表現:

`動画編集を1本1万円で外注するなら、3本で3万円。先着30名のToC導入協力価格29,800円は、3本分の編集外注費とほぼ同じです。`

必須の説明:

`動画編集を1本10,000円で3本外注した場合との比較。外部AI・クラウドサービスの利用料と顧客の作業時間は含まず、副業収益や売上による回収を保証しない。`
