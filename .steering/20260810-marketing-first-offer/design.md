# 最初の商品案を決める設計

更新日: 2026-08-10

注記: 商品の中心価値は、`.steering/20260829-marketing-brand-worldview-value/` により、顧客のブランドや世界観に合う画像を生成し、その画像で動画を完成させることへ更新された。

## 商品の構造

```text
顧客の知識や経験
  -> 顔出しなしの最初の一本
     構成 / 画像 / 映像 / 音声 / 編集
  -> 顧客による採用
  -> 制作システムと制作データの引き渡し
  -> 次のテーマから制作を始められる
```

## 商品の境界

- 動画一本だけの制作代行にしない
- 自分で何も判断しなくてよい完全自動商品にしない
- 最初の一本と、次も作れる仕組みを一つの導入商品にする
- 納品後の保守、更新、追加制作は別の提供内容として分ける

## 価格を決める順序

```text
顧客候補5人への聞き取り
  -> 顧客像と必要範囲の確認
  -> 一件以上の試験納品
  -> 作業時間 / 外部費用 / 修正 / 支援負担の計測
  -> 導入費と支払条件の決定
```
