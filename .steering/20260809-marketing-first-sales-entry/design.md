# 最初の販売対象と入口を決める設計

更新日: 2026-08-09

注記: 最初の顧客像は、`.steering/20260810-marketing-first-persona/` の決定により、`自分の知識や経験を、顔出しなしの動画にしたい副業個人` へ絞られた。

## 最初の販売入口

```text
副業として発信や反応検証をしたい
  -> 動画にしたい具体的なテーマがある
  -> 制作負担で完成または公開できていない
  -> ToC で構成、画像、映像、音声、編集まで完成
  -> 顧客が完成動画を採用
  -> 次の制作を始められる仕組みを受け取る
```

## 顧客への表現

`自分の想いを動画にしたい人`

ここでいう想いには、経験、知識、物語、企画、伝えたい価値観を含む。どの用途を最初に売るかは、直近の制作行動と支払う意思を顧客との会話で確認してから絞る。

## 次の市場との境界

- 小規模ビジネス運営者は削除せず、事業向け実例と商品連携の条件が揃うまで次の市場として保持する
- 画像一括生成は削除せず、最初の動画制作に必要な画像工程と、将来の単独商品として検証する
